## Assumptions & Decisions（假设与决策）
1. 不改全站 Layout 的基线边距（避免影响所有页面），采用**单页覆盖**的方式实现“EX-01 边距更窄”。
2. “边距更窄”的含义：在桌面端（md/lg）减少左右留白，让内容更铺开；移动端保持现有 `px-5`，不变得拥挤。
3. 只做轻度收紧：通过字号/行高/间距/容器宽度调整达成，不引入复杂新布局（不改两栏结构）。

## Proposed Changes（改动方案）

### 1) ExhibitionDetail：引入“双层容器”覆盖 Layout 边距（本页更贴边）
文件：`src/pages/ExhibitionDetail.tsx`

将现有最外层：
- `py-12 max-w-[999px] mx-auto`

替换为“两层结构”：

1) **gutter override 层（抵消 Layout padding，再加回更小的 padding）**
- `-mx-5 md:-mx-12 lg:-mx-20 px-5 md:px-8 lg:px-12`
  - 效果：在 md/lg 下把 Layout 的 `px-12/px-20` 变为更窄的 `px-8/px-12`（更贴边）
  - 移动端仍是 `px-5`（保持不挤）

2) **内容层（控制宽度与上下间距，避免叠加过厚）**
- `mx-auto max-w-[1040px] pt-2 md:pt-4 pb-6 md:pb-8`
  - 去掉 `py-12`，避免与 Layout 的 pt/pb 叠加
  - `max-w` 略放宽（比 999px 更舒服），减少“内容区过窄导致留白显著”的观感

### 2) Header：缩小字号与留白（标题/引言更像“文章页”而不是“海报”）
文件：`src/pages/ExhibitionDetail.tsx`

建议改动：
- Header 容器：
  - `mb-24` → `mb-14 md:mb-16`
- meta：
  - `mb-4` → `mb-3`
- H1：
  - `text-4xl md:text-5xl mb-10` → `text-3xl md:text-4xl mb-6 md:mb-7`
  - 行高：`leading-tight` → `leading-[1.15]`
- prologue（引言）：
  - `text-lg` → `text-base md:text-[17px]`
  - 左侧缩进：`pl-8` → `pl-5 md:pl-6`
  - （可选）`border-l-2` → `border-l`，让装饰更克制

### 3) 单元列表：收紧卡片密度（但保留移动端可点按）
文件：`src/pages/ExhibitionDetail.tsx`

建议改动：
- 每条 Link：
  - `py-10 md:py-14` → `py-7 md:py-9`（或更明显：`py-6 md:py-8`）
- 左侧编号+标题的 gap：
  - `gap-6 md:gap-12` → `gap-4 md:gap-8`
- 单元标题字号：
  - `text-xl md:text-3xl` → `text-lg md:text-2xl`
- hover 位移：
  - `translate-x-4` → `translate-x-3`
- 右侧圆形按钮：
  - `w-12 h-12` → `w-10 h-10 md:w-11 md:h-11`
  - ArrowRight 图标：`20` → `18`（可选）

### 4) 可选：抽取“窄边距页面容器”样式（便于后续复用）
如果后续 EX-02/EX-03 也要同样策略，建议二选一：

**方案 A（推荐）**：新增 TS 常量（改动小、可复用）
- 新文件：`src/constants/layout.ts`（或 `src/styles/page.ts`）
- 导出常量：
  - `PAGE_GUTTER_NARROW = "-mx-5 md:-mx-12 lg:-mx-20 px-5 md:px-8 lg:px-12"`
  - `PAGE_MAX_W_WIDE = "mx-auto max-w-[1040px]"`

**方案 B**：在 `src/index.css` 的 `@layer utilities` 定义 `.page-gutter-narrow`
（适合全站多处复用，但会增加全局样式面）

本次需求只改 EX-01，可先不抽取，等确认样式后再做复用。
