# 浏览展品详情页重设计计划（A-0002 等）

## Summary（目标概述）
重设计“浏览展品点开后的详情页”（路由 `/collection/:id?img=`，文件 `src/pages/CollectionDetail.tsx`）：
- 左侧图片可 **点击打开弹窗灯箱放大**（支持关闭/ESC，多图可左右切换）。
- 减少左侧灰色背景占位（去掉大 padding 与 `min-h`）。
- 右侧信息按固定顺序展示：**图片名称（按当前 img index）→ 图片来源 → 图说 → 跳转至对应展览章节**。
- “跳转章节”支持**列出全部出现位置**（同一展品可能出现在多个单元），跳到 `/hall/:exId/:unitId`。

## Assumptions & Decisions（假设与决策）
1. 不引入新依赖（不安装第三方 lightbox），使用现有 `motion/react` + Tailwind + React 实现灯箱。
2. 灯箱交互选择：**弹窗灯箱（推荐）**。
3. “跳转至对应展览章节”目标：**跳到单元正文** `/hall/:exId/:unitId`。
4. 若展品出现在多个单元：**列出全部出现位置**。
5. URL `?img=` 将与灯箱的当前图保持同步（便于分享与刷新一致，并驱动右侧文字同步）。
   - 仅更新 `search`，不改变 `pathname`，避免触发全局 `ScrollToTop`（此前已实现按 pathname 复位）。

## Proposed Changes（改动方案）

### 1) 内容层增加“出现位置查询”函数
文件：`src/content/exhibitions/index.ts`

新增类型与函数：
- `export type ArtifactOccurrence = { exId; exTitle; unitId; unitTitle }`
- `export function getArtifactOccurrences(artifactId: string): ArtifactOccurrence[]`

实现要求：
1. 基于当前导出的 `exhibitions` 静态数据，在模块初始化时建立索引：
   - `Map<artifactId, ArtifactOccurrence[]>`
2. 遍历 `exhibitions -> units -> artifacts` 收集出现位置。
3. 对同一 `exId/unitId` 去重（避免重复链接）。

### 2) 详情页 UI 重排与信息顺序统一
文件：`src/pages/CollectionDetail.tsx`

#### 2.1 左侧图片区（减少占位）
- 移除 `min-h-[70vh]`
- 将 `p-12 md:p-20` 改为更克制的 `p-6 md:p-10`（或更小）
- 图片本身加 `max-h`（例如 `max-h-[65vh] md:max-h-[70vh]`），并保持 `object-contain`

#### 2.2 图片点击打开灯箱
实现方式（二选一，推荐 A）：

**A. 抽成组件（推荐，可复用）**
- 新增文件：`src/components/Lightbox.tsx`
  - props：`isOpen, urls, index, onClose, onPrev, onNext, ariaLabel`
  - 使用 `AnimatePresence` + `motion.div` 做淡入淡出

**B. 直接写在 CollectionDetail 内（最小改动）**
- 在 `CollectionDetail.tsx` 内写 `isLightboxOpen` 状态与 overlay JSX。

交互要求：
1. 点击图片打开灯箱
2. 点击遮罩关闭
3. ESC 关闭
4. 多图时提供“上一张/下一张”按钮（可选加键盘左右键）
5. 打开灯箱时锁定 body 滚动，关闭恢复

#### 2.3 右侧信息按需求顺序
右侧内容顺序固定为：
1. **图片名称**：`displayTitle`（用 `getImageTitleForIndex(art.title, safeIndex, total)`）
2. **图片来源**：`art.source`
3. **图说**：`art.description`
4. **跳转至对应展览章节**：`getArtifactOccurrences(art.id)` 列表

跳转入口 UI：
- 标题可用中文（例如“对应展览章节”），或用更克制的 meta 样式（不影响需求）
- 列表项文案建议：`{展览标题} · {单元标题}`，链接到 `/hall/${exId}/${unitId}`

> 可选增强（后续再做）：链接加 hash `/hall/${exId}/${unitId}#entry-${art.id}` 直接定位正文条目；本次先满足用户明确的路径格式即可。

#### 2.4 `?img=` 同步策略（关键）
- 灯箱切图时用 `useNavigate()` 更新 `search`：
  - `navigate({ pathname: location.pathname, search: '?img=' + nextIndex }, { replace: true, state: location.state })`
- 只更新 search，不更新 pathname，避免触发滚动复位。

### 3) 可访问性（A11y）要求
灯箱必须满足：
- `role="dialog"` + `aria-modal="true"`
- 关闭按钮 `aria-label="关闭"`
- ESC 关闭
- 打开时将焦点移到关闭按钮（简单 focus 管理即可）
- 锁定背景滚动
